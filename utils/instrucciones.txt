
A INSTALAR servicio ssh
He modificado el script para hacer todo automático. IMPORTANTE: es necesario instalar el servicio ssh en cada equipo para poder ejecutar comandos. Así que primero de todo hay que entrar en cada equipo y hacer en un terminal
$ sudo apt update
$ sudo apt install openssh-server
$ sudo ssh-keygen -A

REINICIAR CADA PC PARA QUE INIICALICE el servicio ssh con las nuevas claves generadas.

Con esto, ya nos podemos conectar y hacer el resto de cosas de forma remota.
